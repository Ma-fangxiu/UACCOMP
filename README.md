# UAC 助手

本插件可以通过检测权限让 ClassIsland 在启动时以管理员身份启动。

> [!NOTE]
> **温馨提示**：第一次食用请到设置界面开启功能，本插件不默认开启

## 使用方法

1. 在插件市场下载本插件；
2. 在插件设置界面中，启动插件功能
3. 放心(?食用
